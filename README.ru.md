# Модуль расширенной истории звонков для Dzvin PBX

**[Українською](README.uk.md)** | **[English](README.md)** | **Русский**

Форк модуля MikoPBX **ModuleExtendedCDRs** (на основе mikopbx/ModuleExtendedCDRs v1.43) для Dzvin PBX:
подробная история звонков с расширенными фильтрами, отчёты (PDF, XLSX, JSON), отчёты по расписанию на e-mail,
экспорт на HTTP-адрес и скачивание записей разговоров. Проверок лицензии в модуле нет.

Требуется Dzvin PBX 2024.1.114 или новее. Установка: **Модули** -> **Маркетплейс** либо загрузка `.zip` из релиза
GitHub через **Установка модуля**.

Основной язык документации - украинский, см. [README.uk.md](README.uk.md).
